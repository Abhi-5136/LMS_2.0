## How to Test

### 1. Start the backend server:
Open a terminal in backend and run node server.js

### 2. Start the frontend server:
Open a terminal in lms2 and run npm run dev

### 3. Register/Login:
Navigate to your frontend, register a new account, and login. (Note: by default a registered account is a "user" role. You can create an admin account directly in MongoDB, or modify the /register request momentarily to pass "role": "admin" if you want an admin account).

### 4. Use the App:
Check out the admin and user dashboards, add some books, and issue them!
